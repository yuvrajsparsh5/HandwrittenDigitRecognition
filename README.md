# Handwritten Digit Recognition using ANN

## Overview
This project classifies handwritten digits from 0 to 9 using an Artificial Neural Network (ANN) implemented in Python with TensorFlow and Keras.

## Dataset
The project uses the MNIST dataset, containing grayscale images of handwritten digits.

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

## Workflow
1. Load the MNIST dataset.
2. Normalize the image pixel values.
3. Build and train the neural network.
4. Evaluate the model on test images.
5. Predict handwritten digits.

## How to Run
Install the required libraries:

`pip install tensorflow numpy matplotlib`

Run the Python script or open the notebook in Google Colab or Jupyter Notebook.
